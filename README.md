# bookshelf-drost-us

Static site generator for **bookshelf.drost.us** — 321 books, 361 routes. No framework, no bundler,
no CSS processor. Nunjucks and Node, output to `dist/`, deployed on Cloudflare Pages.

```bash
npm ci
npm run build      # validate → resolve slugs → render → emit sitemap → print report
npm run qa         # 87 checks; exits 1 on any failure
```

Optional, needs Playwright and a local Chromium — not installed by `npm ci`, never run in CI:

```bash
node tools/visual-check.mjs    # renders 15 page types at 390px and 1440px, checks for regressions
node tools/make-og.mjs         # regenerates src/share.png from the four most recent reads
node tools/md-to-pdf.mjs docs/GO-LIVE.md
```

## How data reaches this repo

```
Goodreads → Notion → [Public? checkbox] → sync Worker → this repo → Cloudflare Pages
```

One way, always. Nothing flows backward, and nothing here is hand-edited into `books.json`.

The Worker lives at `tools/bookshelf_sync_worker.js` (deployed separately to Cloudflare, not run
by this build). It writes two things: `src/data/books.json` and `src/covers/{goodreadsId}.jpg`.

## Layout

```
src/
  data/
    books.json              written by the Worker — never hand-edit
    slugs.json              slug ledger + drift detector. Notion is authoritative; this is backup
    themes.json             hand-maintained: display name, slug, editorial order, intro
    clusters.json           hand-maintained: /picks groupings
    standouts.json          hand-maintained: id -> {cluster, note}
  styles/
    tokens.css              @font-face + the :root block, copied verbatim
    site.css                everything else from the original <style>, verbatim
    pages.css               layout for the generated pages only
  assets/fonts/             Archivo 600-800, Inter 400-600 — latin WOFF2, self-hosted
  assets/js/                extracted from the SPA by line range, not rewritten
  templates/                _layout.njk + partials + one template per page type
  pages/                    body copy as markdown-with-front-matter
  covers/                   {goodreadsId}.jpg — written by the Worker's /covers route
  index.html                the original SPA; still a build input for the home page
  share.png                 og:image, generated by tools/make-og.mjs
tools/                      build.mjs validate.mjs derive.mjs slugify.mjs qa.mjs + dev-only tools
docs/                       reports and runbooks
dist/                       generated, gitignored — Pages builds it
```

## Rules that bite

- **Never edit `dist/`.** Every generated file carries a DO-NOT-EDIT header, and the next build
  overwrites it.
- **Never hand-edit `books.json`.** The Worker rebuilds it wholesale from Notion on every sync.
  Anything not in the Notion allowlist must live in a companion file — that's why `slugs.json`,
  `standouts.json` and `clusters.json` exist.
- **Slugs are frozen.** Written once, never overwritten, even if the title changes. That's the
  point: a live URL doesn't move because someone tidied a subtitle. Notion holds the authoritative
  slug; `slugs.json` is the backup and drift detector. QA re-runs the assignment and asserts
  nothing moves.
- **Read `conn`, never `edges`.** `edges` is position-based and corrupts silently on reorder; it's
  regenerated from `conn` every sync. Connection lists union both directions before deduping — 75
  pairs are one-way and would otherwise render on only one of the two books.
- **`Public?` is the only visibility gate.** The Worker filters on it at the source, so every book
  in `books.json` is public. The gate is still checked explicitly so it keeps working if that ever
  changes.
- **Full summary and core ideas appear on exactly one URL** — the book page. Hubs get one teaser
  line, hard-capped at 130 characters. QA enforces it.
- **No ratings.** No rating field, no `Review`, no `aggregateRating`. Ever.
- **CSS is moved, never rewritten.** `site.css` must stay byte-identical to the original block.
- **Nav contains only routes that exist.** No entry for a page that isn't built.

## The build fails on

empty title · missing or duplicate `id` · duplicate `slug` · zero themes or a theme outside
`themes.json` · a `conn` reference to an unknown id · a sitemap route not written to `dist/` ·
a duplicate title tag or description · any `fonts.googleapis.com` reference in output HTML.

Warnings — reported, never fatal: missing cover, missing ISBN, `pages: "0"`, prose below the
150-word target, connections pointing at non-public books (filtered from output).
